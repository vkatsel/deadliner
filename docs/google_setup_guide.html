Google Cloud Setup Guide

Estimated Setup Time: 3–5 minutes • Last Updated: September 23, 2026 • Version 2.1
Zero-Knowledge & Complete Privacy: Deadliner operates entirely locally on your workstation. Setting up your personal Google Cloud project ensures that no tokens, credentials, or calendar entries are ever handled by an intermediary server. Creating Desktop OAuth credentials in Google Cloud is 100% free and requires no billing information.

Step 1. Access Google Cloud Console

Navigate to the official console at console.cloud.google.com and sign in with your Google account (for example, your university email @kse.org.ua or your personal account @gmail.com).

Step 2. Create a New Project

  1. In the top-left navigation bar, click on the project dropdown next to the Google Cloud logo.
  2. In the project dialog modal, click New Project.
  3. Enter a project name (e.g., Deadliner-Sync) and click Create.
  4. Wait a few seconds for provisioning, and verify your new project is selected in the top bar.

Step 3. Enable Google Calendar & Classroom APIs

  1. Open the API Library: console.cloud.google.com/apis/library.
  2. Search for Google Calendar API and click the Enable button.
  3. Return to the library, search for Google Classroom API, and click Enable as well.

Step 4. Configure OAuth Consent Screen

  1. Navigate to the consent screen setup: console.cloud.google.com/apis/credentials/consent.
  2. Select User Type: External and click Create.
  3. Fill in the mandatory fields:
    • App name: Deadliner
    • User support email: Select your personal or student Google email.
    • Developer contact email: Enter your email address.
  4. Click Save and Continue.
  5. Under the Scopes step, you may leave it as default or click Save and Continue (Deadliner requests the required scopes dynamically during client authorization).
  6. Test Users Tab (Important): Click + ADD USERS and add the Google email address with which you will log into Deadliner. Click Save and Continue.

Step 5. Create Desktop OAuth Client ID

  1. Go to the Credentials page: console.cloud.google.com/apis/credentials.
  2. Click + Create Credentials in the top toolbar → select OAuth client ID.
  3. In the Application type dropdown, select Desktop app.
  4. In the name field, enter Deadliner Desktop Client and click Create.
  5. In the confirmation dialog, click Download JSON to save your client secrets file.

Step 6. Import Credentials into Deadliner (1-Click Import)

Deadliner provides an interactive CLI wizard to import your downloaded JSON credentials directly:

deadliner menu
  1. In the main interactive menu, select option 7 (Login / Configure Services).
  2. Select sub-option e (Import / Update Google Client Secrets).
  3. Select option 1 (Paste raw JSON content) and paste the complete content of your downloaded JSON file into the terminal!

Deadliner will validate the JSON structure and securely store it in your local configuration directory at ~/.deadliner/client_secret.json.

❓ Frequently Asked Questions & Troubleshooting

Notice: "Google hasn't verified this app"

Because your Google Cloud Project is set to external testing mode for your personal use, Google displays a standard warning on the first login. Simply click Advanced → Go to Deadliner (unsafe) → and grant the requested calendar access permissions.

Error: "403 access_denied"

This occurs if the account you are signing in with was not added to the Test Users list in Step 4. Re-open OAuth Consent Screen, go to the Test users section, add your email, and save.
