Червоні дедлайни (Tomato Red)

Усі завдання з Moodle та Google Classroom потрапляють у календар у яскраво-червоному кольорі (Google colorId 11). Deadliner створює чітку 15-хвилинну подію перед дедлайном, тож ви більше ніколи не сплутаєте північ (00:00) із кінцем дня (23:59).

Лекції розкладу KSE

Пряма інтеграція зі schedule.kse.ua класифікує теоретичні заняття у спокійний шавлієвий колір (Sage Green, Google colorId 2). Аудиторії, імена викладачів та Zoom-посилання акуратно вносяться в опис події календаря.

Практики розкладу KSE

Практичні заняття, семінари та лабораторні позначаються блакитним (Peacock Blue, Google colorId 7). Deadliner розпізнає розподіл за підгрупами (наприклад, Група А / B), відображаючи лише ті пари, які призначені саме вам.

24h фонова автосинхронізація

Налаштуйте один раз і забудьте. Deadliner інтегрується у системні планувальники завдань вашої ОС (Windows Task Scheduler через schtasks або стандартний UNIX cron) для щоденної фонової синхронізації без витрат батареї.

Windows • Linux • macOS Без постійних фонових процесів
🧹

Прибирання скасованих подій

Якщо викладач переніс, скасував пару або відкликав завдання у Moodle, Deadliner використовує стабільні SHA-256 ідентифікатори (extendedProperties), автоматично та акуратно видаляючи застарілі події.

Швидкий старт

Миттєве встановлення без зайвих налаштувань

Deadliner написаний на сучасному Python з мінімальною кількістю залежностей. Повна синхронізація займає менше 2 хвилин.

1

Встановлення з репозиторію

Python 3.10+

Склонуйте репозиторій та встановіть пакет у середовище:

git clone https://github.com/vkatsel/deadliner.git && cd deadliner && pip install -e .
АБО Завантажити з GitHub Releases v1.5.6
2

Перший запуск та автоналаштування PATH

Без клопоту

За замовчуванням pip встановлює консольні утиліти у внутрішній каталог скриптів Python, який часто відсутній у системній змінній PATH. При першому запуску виконайте команду напряму через модуль Python:

python -m deadliner

✓ Автоналаштування в 1 клік: Deadliner автоматично помітить відсутність у PATH та запропонує додати себе до системних шляхів. Після підтвердження просто відкрийте новий термінал і вводьте команду deadliner з будь-якого місця!

Потрібно підключити доступ до Google Календаря та Classroom? Скористайтеся нашою 3-хвилинною Google Інструкцією з налаштування →

3

Повна синхронізація однією командою

Дедлайни + Розклад

Миттєво надішліть усі дедлайни та розклад KSE до Google Календаря:

deadliner sync-all
4

Увімкнення щоденної фонової автосинхронізації

Налаштував і забув

Створіть системне фонове завдання (наприклад, о 08:00 щоранку):

deadliner cron enable --time 08:00

Отримати найближчі дедлайни

Підключається до ваших облікових записів у Moodle та Google Classroom, завантажує всі активні завдання та виводить терміновий список з чітким сортуванням за датою здачі.

$ deadliner fetch

Приватність за замовчуванням

Нуль віддалених серверів. Нуль телеметрії.

Ваші університетські завдання, оцінки та розклад — це ваші особисті дані. Deadliner працює суворо локально.

🔒 Локальне збереження токенів

OAuth-токени, токени сесії Moodle та облікові дані KSE зберігаються виключно у вашому домашньому каталозі (~/.deadliner.json). Вони ніколи не залишають ваш пристрій.

🌐 Прямі запити до офіційних API

Мережевий трафік шифрується і йде напряму між вашим комп'ютером та API Moodle, Google і schedule.kse.ua. Жодних проміжних серверів-посередників чи проксі.

🛡️ Мінімальні дозволи Google Scopes

Deadliner запитує лише ті дозволи Google Calendar і Classroom, які критично необхідні для синхронізації. Повна відповідність вимогам Google Limited Use.
