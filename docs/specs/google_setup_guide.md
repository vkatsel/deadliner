# Покроковий гайд: Налаштування Google Cloud Project для Deadliner

Цей посібник детально пояснює, як за 3–5 хвилин створити безкоштовний персональний проєкт у **Google Cloud Console**, отримати облікові дані (`client_secret.json`) та надати Deadliner доступ до Google Calendar та Google Classroom.

---

## 🔒 Чому потрібен власний Google Cloud Project?

1. **Zero-Knowledge & Повна Приватність:**
   Deadliner працює виключно локально на вашому комп'ютері. Проєкт не має віддалених серверів чи бази даних. Усі токени зберігаються лише на вашому пристрої у файлах `~/.deadliner.json` та `~/.deadliner_google_token.json`.
2. **Безкоштовно та Безпечно:**
   OAuth 2.0 Client ID для додатків типу *Desktop App* є 100% безкоштовним та не потребує введення платіжних даних (банківських карток).
3. **Пряма взаємодія:**
   Запити синхронізації надсилаються напряму з вашого комп'ютера до серверів Google.

---

## 🚀 Покрокова інструкція

### Крок 1. Відкрийте Google Cloud Console
1. Перейдіть за посиланням: [console.cloud.google.com](https://console.cloud.google.com/).
2. Увійдіть у свій Google-акаунт (рекомендуємо використовувати той акаунт, в календар якого ви плануєте синхронізувати дедлайни — наприклад, `@kse.org.ua` або особистий `@gmail.com`).

---

### Крок 2. Створіть новий проєкт
1. У верхній панелі натисніть на випадаючий список проєктів (поруч із логотипом *Google Cloud*).
2. У вікні, що з'явиться, натисніть кнопку **New Project** (у правому верхньому кутку).
3. Введіть назву проєкту, наприклад:
   - **Project Name:** `Deadliner-Sync`
4. Натисніть **Create** та зачекайте кілька секунд, поки проєкт створиться.
5. Переконайтеся, що новостворений проєкт вибрано у верхній панелі.

---

### Крок 3. Увімкніть необхідні Google API
Вам потрібно увімкнути два API: **Google Calendar API** та **Google Classroom API**.

1. Відкрийте **API Library**: [console.cloud.google.com/apis/library](https://console.cloud.google.com/apis/library).
2. У полі пошуку введіть `Google Calendar API` -> натисніть на знайдений результат -> натисніть кнопку **Enable** (Увімкнути).
3. Знову відкрийте **Library**, введіть `Google Classroom API` -> відкрийте його -> натисніть кнопку **Enable** (Увімкнути).

---

### Крок 4. Налаштуйте OAuth Consent Screen (Екран згоди)
1. Перейдіть до розділу **OAuth consent screen**: [console.cloud.google.com/apis/credentials/consent](https://console.cloud.google.com/apis/credentials/consent).
2. Оберіть тип користувачів (**User Type**):
   - **External** (Зовнішній) — рекомендовано для будь-яких акаунтів.
   - *(Якщо ви використовуєте корпоративний Google Workspace від KSE і синхронізуєтесь тільки з ним, можна також обрати Internal).*
3. Натисніть **Create**.
4. Заповніть обов'язкові поля екрану:
   - **App name:** `Deadliner`
   - **User support email:** оберіть вашу пошту із випадаючого списку.
   - **Developer contact information:** введіть вашу пошту.
5. Натисніть **Save and Continue** (Зберегти та продовжити).
6. **Вкладка Scopes (Області доступу):** можна пропустити, натиснувши **Save and Continue** (Deadliner самостійно запитає необхідні скоупи при першому вході).
7. **Вкладка Test Users (Тестові користувачі) — ВАЖЛИВО:**
   - Якщо на кроці 2 ви обрали *External*, ваш додаток перебуває у статусі *Testing*.
   - Натисніть **+ ADD USERS**.
   - Введіть вашу адресу електронної пошти (той самий Google-акаунт, через який ви будете входити в Deadliner).
   - Натисніть **Add**, потім **Save and Continue**.

---

### Крок 5. Створіть Credentials (Ключі доступу)
1. Перейдіть до розділу **Credentials**: [console.cloud.google.com/apis/credentials](https://console.cloud.google.com/apis/credentials).
2. У верхній панелі натисніть **+ Create Credentials** -> оберіть **OAuth client ID**.
3. У випадаючому меню **Application type** оберіть **Desktop app**.
4. У полі **Name** вкажіть: `Deadliner Desktop Client`.
5. Натисніть кнопку **Create**.

---

### Крок 6. Завантажте або скопіюйте облікові дані
Після створення з'явиться вікно "OAuth client created":
- Натисніть **DOWNLOAD JSON** (файл завантажиться з довгою назвою на зразок `client_secret_XXX...json`).
- Або просто скопіюйте **Client ID** та **Client Secret**.

---

## 💻 Як підключити ключі до Deadliner?

Deadliner підтримує **3 зручні способи**, що позбавляють потреби вручну шукати системні папки:

### Варіант А (Найшвидший — через інтерактивне меню):
1. Відкрийте термінал і запустіть інтерактивне меню:
   ```bash
   deadliner menu
   ```
2. Оберіть пункт `7` (**Login / Configure Services**).
3. Оберіть пункт `e` (**Import / Update Google Client Secrets**).
4. Оберіть варіант `1` (**Paste raw JSON content**) і просто вставте весь вміст завантаженого файлу `client_secret.json` у вікно терміналу (або оберіть варіант `3` і введіть Client ID та Client Secret вручну).
5. Deadliner автоматично валідує формат і збереже файл у потрібну директорію (`~/.deadliner/client_secret.json`).

### Варіант Б (Через команду входу):
1. Запустіть:
   ```bash
   deadliner login google
   ```
2. Якщо файл ще не налаштовано, програма запропонує вставити JSON, перетягнути завантажений файл мишкою прямо в термінал або вказати шлях.

### Варіант В (Вручну):
Збережіть завантажений JSON-файл за шляхом:
- **Windows:** `C:\Users\<ВашКористувач>\.deadliner\client_secret.json`
- **macOS / Linux:** `~/.deadliner/client_secret.json`

## ❓ Часті запитання та вирішення проблем (FAQ)

### 1. Попередження: *"Google hasn’t verified this app"* (Google не перевірив цю програму)
При першій авторизації в браузері Google покаже екран із попередженням.
- **Чому це з'являється?** Оскільки ви створили власний особистий проєкт у Google Cloud, Google позначає його як приватний/неперевірений для широкого загалу.
- **Що робити?** Натисніть **Advanced** (Додатково / Посилання внизу зліва) -> натисніть **Go to Deadliner (unsafe)** (Перейти до сторінки Deadliner) -> надайте дозволи на читання курсів та керування календарем.

### 2. Помилка `403: access_denied`
Якщо при вході ви бачите помилку доступу:
- Переконайтеся, що на **Кроці 4** у розділі **Test Users** ви додали саме той email, під яким намагаєтеся увійти.

### 3. Де зберігається токен сесії?
Після успішної авторизації токен зберігається у файлі `~/.deadliner_google_token.json`. Deadliner автоматично оновлює його за потреби (через Google refresh token), тому повторно входити в браузер кожного дня не потрібно.
