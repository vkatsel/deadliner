Visual Clarity, Zero Friction

Built specifically to tackle portal fragmentation and the cognitive friction that leads to missed assignments.

🔴

Tomato Red Deadlines

All Moodle and Google Classroom submissions sync as vibrant Tomato Red (Google colorId 11). Deadliner places a crisp 15-minute event pointing right at the exact cutoff moment so you never confuse midnight (00:00) with end-of-day (23:59).

Google Calendar Color #11 Explicit Cutoff Badging
🟢

KSE Schedule Lectures

Direct ingestion from schedule.kse.ua automatically categorizes theory lectures into calming Sage Green (Google colorId 2). Classrooms, professors, and zoom links are neatly placed into the calendar event description.

Google Calendar Color #2 Classroom & Lecturer Auto-fill
🔵

KSE Schedule Practices

Practice sessions, labs, and interactive seminars sync in Peacock Blue (Google colorId 7). Deadliner parses your subgroup designations (e.g. Group A / B) so you only see the sessions you actually need to attend.

Google Calendar Color #7 Subgroup-Aware Filtering
⚡

1-Click Clipboard Login

No developer tools hacking or manual JSON copying. Simply launch deadliner login kse, log in via your browser, copy your session token to clipboard, and Deadliner automatically captures it instantly.

schedule.kse.ua Integration Zero-Pain Auth
⏰

24h Background Auto-Sync

Set it and forget it. Deadliner configures native OS schedulers (Windows Task Scheduler via schtasks or standard UNIX cron) to sync your calendar silently every morning without battery drain.

Windows • Linux • macOS Zero Background Daemon
🧹

Cancellation Reconciliation

When a professor reschedules, cancels a lecture, or retracts an assignment on Moodle, Deadliner uses SHA-256 stable tracking IDs (extendedProperties) to automatically prune deleted events cleanly.

Deterministic Idempotency Zero Ghost Events
Get Up & Running

Fast, Zero-Config Setup

Deadliner is written in modern Python with minimal dependencies. You can be fully synced in under 2 minutes.

1

Install from GitHub

Python 3.10+

Install directly into your Python environment via pip:

pip install git+https://github.com/vkatsel/deadliner.git
2

Launch Interactive Menu

All-in-One CLI

Open the interactive command center to connect accounts and test syncs:

deadliner menu
3

One-Command Full Sync

Deadlines + Schedule

Push your latest deadlines and KSE classes straight to your Google Calendar:

deadliner sync-all
4

Enable Daily Background Automation

Set & Forget

Register a native daily task (e.g. 08:00 AM every day):

deadliner cron enable --time 08:00

Privacy By Design

Zero Remote Servers. Zero Telemetry.

Your university assignments, grades, and schedules are personal. Deadliner is strictly client-side.

🔒 Local Token Storage

OAuth tokens, Moodle session tokens, and KSE credentials are stored strictly in your local home directory (~/.deadliner.json). They never leave your device.

🌐 Direct University APIs

Network requests travel directly between your personal machine and Moodle, Google, and schedule.kse.ua APIs. There is no intermediate Deadliner backend proxy.

🛡️ Minimal Google Scopes

Deadliner only requests the Google Calendar and Classroom scopes strictly required for synchronization. It adheres 100% to Google Limited Use requirements.
