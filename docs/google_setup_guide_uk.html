Посібник: Налаштування Google Cloud Project

Час налаштування: 3–5 хвилин • Оновлено: 23 вересня 2026 р. • Версія: 2.1
EN UA
Zero-Knowledge & Повна Приватність: Deadliner працює повністю локально на вашому комп'ютері. Налаштування персонального проєкту в Google Cloud гарантує, що жодні ваші облікові дані чи події календаря не потрапляють на сторонні сервери. Створення Desktop OAuth клієнта є 100% безкоштовним і не вимагає платіжних даних.

Крок 1. Відкрийте Google Cloud Console

Перейдіть за посиланням console.cloud.google.com та увійдіть під своїм Google-акаунтом (наприклад, університетським @kse.org.ua або особистим @gmail.com).

Крок 2. Створіть новий проєкт

  1. У верхньому лівому кутку натисніть на меню вибору проєкту поруч із логотипом Google Cloud.
  2. У діалоговому вікні натисніть New Project (Новий проєкт).
  3. Введіть назву проєкту (наприклад, Deadliner-Sync) та натисніть Create.
  4. Зачекайте декілька секунд і переконайтеся, що створений проєкт вибрано у верхній панелі.

Крок 3. Увімкніть Google Calendar & Classroom API

  1. Перейдіть до бібліотеки API: console.cloud.google.com/apis/library.
  2. Знайдіть Google Calendar API та натисніть кнопку Enable (Увімкнути).
  3. Поверніться до бібліотеки, знайдіть Google Classroom API та також натисніть Enable.

Крок 4. Налаштуйте OAuth Consent Screen (Вікно згоди)

  1. Перейдіть до сторінки налаштування екрана згоди: console.cloud.google.com/apis/credentials/consent.
  2. Оберіть тип користувача External (Зовнішній) та натисніть Create.
  3. Заповніть обов'язкові поля:
    • App name: Deadliner
    • User support email: оберіть вашу адресу електронної пошти.
    • Developer contact email: вкажіть вашу адресу електронної пошти.
  4. Натисніть Save and Continue.
  5. Розділ Scopes можна пропустити (натисніть Save and Continue).
  6. Вкладка Test Users (Важливо): Натисніть + ADD USERS та додайте свій власний email, під яким ви будете авторизуватися в Deadliner. Натисніть Save and Continue.

Крок 5. Створіть OAuth Client ID

  1. Перейдіть до розділу облікових даних: console.cloud.google.com/apis/credentials.
  2. Натисніть + Create Credentials у верхній панелі → оберіть OAuth client ID.
  3. У випадаючому списку Application type оберіть Desktop app (Десктопний додаток).
  4. У полі назви введіть Deadliner Desktop Client та натисніть Create.
  5. У спливаючому діалоговому вікні натисніть Download JSON (або скопіюйте Client ID та Client Secret).

Крок 6. Додайте ключі в Deadliner (Швидкий імпорт в 1 клік)

Deadliner підтримує швидку вставку ключів прямо в терміналі через інтерактивне меню:

deadliner menu
  1. У головному меню оберіть пункт 7 (Login / Configure Services).
  2. Оберіть підпункт e (Import / Update Google Client Secrets).
  3. Оберіть опцію 1 (Paste raw JSON content) та вставте весь вміст завантаженого файлу в термінал!

Deadliner автоматично перевірить структуру даних та збереже файл у ~/.deadliner/client_secret.json.

❓ Вирішення поширених запитань (FAQ)

Попередження "Google hasn’t verified this app" під час входу

Це стандартне системне повідомлення платформи Google для особистих проєктів, які перебувають на етапі тестування. Натисніть Advanced (Додатково) → Go to Deadliner (unsafe) → підтвердьте дозвіл на синхронізацію календаря.

Помилка 403: access_denied

Переконайтеся, що на Кроці 4 у розділі Test users (Тестові користувачі) ви вказали саме той Google-акаунт, під яким ви авторизуєтеся в системі.
