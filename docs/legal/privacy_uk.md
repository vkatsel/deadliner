## Відповідність Політиці щодо даних користувачів у службах Google API

> **Використання додатком Deadliner інформації, отриманої від Google API, та її передача будь-яким іншим додаткам здійснюється у повній відповідності до [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включно з Вимогами щодо обмеженого використання (Limited Use Requirements).**

Deadliner **не продає** дані користувачів Google, **не передає** дані стороннім особам, **не використовує** дані користувачів Google для реклами та **не використовує** дані для навчання узагальнених моделей штучного інтелекту чи машинного навчання.

## 1. Вступ та загальний огляд

**Deadliner** — це локальний інструмент командного рядка (CLI) з відкритим вихідним кодом, розроблений для студентів університетів, викладачів та дослідників. Deadliner агрегує навчальні завдання, дедлайни робіт та розклад занять з інституційних платформ (Moodle, розклад KSE) і Google Classroom, автоматично синхронізуючи їх до особистого Google Календаря.

Deadliner функціонує за моделлю **Local-First & Zero-Knowledge**:
- **Відсутність віддалених серверів:** Deadliner не володіє та не підключається до жодних хмарних серверів, кінцевих точок збору телеметрії або сторонніх баз даних.
- **Пряма взаємодія клієнт-API:** Усі мережеві запити надсилаються безпосередньо з вашого комп'ютера до офіційних API (Google APIs, Moodle, KSE Schedule) через захищене з'єднання TLS/HTTPS.
- **Повна відсутність телеметрії:** Ми не збираємо статистику використання, діагностичні логи чи поведінкові дані.

## 2. Області доступу Google OAuth (Scopes) та обробка даних

Deadliner запитує лише мінімально необхідні області доступу OAuth 2.0 для синхронізації календаря та отримання завдань із Google Classroom:

| Область доступу (Scope) | Рівень прав | Призначення та використання |
|---|---|---|
| `https://www.googleapis.com/auth/calendar.events` | Читання / Запис подій | Використовується суворо для створення, оновлення та видалення навчальних дедлайнів і розкладу пар у вашому основному Google Календарі. Deadliner маркує свої події детермінованим метатегом (`deadliner_id`). **Deadliner ніколи не читає, не змінює та не видаляє ваші особисті події календаря.** |
| `https://www.googleapis.com/auth/classroom.courses.readonly` | Тільки читання | Використовується для отримання списку курсів, на які ви зараховані як студент. |
| `https://www.googleapis.com/auth/classroom.coursework.me.readonly` | Тільки читання | Використовується для завантаження особистих навчальних завдань і термінів здачі з Google Classroom. |
| `https://www.googleapis.com/auth/classroom.coursework.students.readonly` | Тільки читання | Використовується для зчитування метаданих завдань і дедлайнів по курсах. |

## 3. Збереження облікових даних та безпека

Усі конфігураційні файли та токени авторизації зберігаються суворо на вашому персональному комп'ютері в домашньому каталозі користувача:

- **`~/.deadliner_google_token.json`**: Містить токени доступу та оновлення Google OAuth2, отримані безпосередньо від сервера автентифікації Google.
- **`~/.deadliner.json`**: Містить налаштування адрес Moodle, токен API Moodle та сесійний токен розкладу KSE.
- **`~/.deadliner/client_secret.json`**: Містить облікові дані десктопного OAuth-клієнта Google Cloud.

Ці файли зберігаються на локальному накопичувачі та захищені правами доступу вашої операційної системи.

## 4. Збереження, відкликання та видалення даних

Оскільки Deadliner не має власної бази даних у хмарі, ви повністю керуєте своїми даними:

### Видалення локальних даних
```bash
# macOS / Linux
rm -f ~/.deadliner.json ~/.deadliner_google_token.json ~/.deadliner/client_secret.json

# Windows (PowerShell)
Remove-Item "$HOME\.deadliner.json", "$HOME\.deadliner_google_token.json", "$HOME\.deadliner\client_secret.json" -ErrorAction SilentlyContinue
```

### Відкликання дозволів Google Account
1. Перейдіть до [Google Account Permissions](https://myaccount.google.com/permissions).
2. Оберіть **Deadliner** у списку додатків.
3. Натисніть **Видалити доступ (Remove Access)**.
