# Deadliner Legal & Compliance Specialist Skill

Use this skill when auditing privacy disclosures, updating terms of service, or preparing Google Cloud OAuth application verification appeals and documentation.

## Core Compliance Mandates

1. **Google API Services User Data Policy Compliance:**
   - Adhere strictly to the **Limited Use** requirements.
   - Disclose exact scopes requested:
     - `https://www.googleapis.com/auth/calendar.events` (creating, updating, and pruning student deadline events).
     - `https://www.googleapis.com/auth/classroom.coursework.me.readonly` (reading course assignments).
     - `https://www.googleapis.com/auth/classroom.courses.readonly` (reading enrolled course names).
   - Certify zero sale, transfer, or monetization of student data.
   - Certify that user data is never used to train machine learning or AI models.

2. **Zero-Knowledge Privacy Certification:**
   - Confirm in all legal policies that Deadliner operates with zero external servers or backend databases.
   - Data stays strictly local on the user's computer.

3. **Google Verification Appeal Documentation:**
   - Reference `docs/legal/google_oauth_verification_appeal.md` for student project justifications, `github.io` hosting explanations, and demo video outlines.
